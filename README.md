Companion code for an anonymous conference submission: a small, exact, reproducible study of when filling a returning truck saves distance but adds counted driver time. Every input is synthetic; no percentage in the outputs describes a real region, company or market.
All maintained code, outputs and reproduction instructions live in backhaul-duty-audit-repo/. Open that folder and follow its README: install dependencies once with pip install -r requirements.txt, then run the scripts from project/ and baseline-study/ as listed there. Everything runs from inside that directory.
The loose files at the top level of this repository are an earlier flat upload of the same material, superseded by the backhaul-duty-audit-repo/ tree. Please use the tree.
